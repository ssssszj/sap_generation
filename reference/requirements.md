# 开题材料需求映射

## 总体流程

- 输入包括 Protocol、CRF 和注册信息。
- 系统先解析材料并定位证据，再形成共享 SAP-IR。
- 按章节生成草稿，运行统计口径与 TFL 检查。
- 输出草稿、检查结果和待确认事项，由用户确认后导出 Word。

## 通用 Harness

- Agent Loop 与任务执行。
- 工具接入与模型调用。
- 会话状态与运行日志。
- 人工确认与任务恢复。

本实现通过 DeepSeek Harness Python SDK 接入上述能力，并提供可安装工具 bundle。

## 四个专项模块

### 统计分析方法设计

输入研究目标、试验设计、终点、分析人群和方案方法。输出估计目标、主分析规格、敏感性分析和待确认事项。检查估计目标五属性以及模型、效应量、检验方法。

### 复杂数据处理

分别使用 `IntercurrentEventPlan` 和 `MissingDataPlan`。伴发事件覆盖停药、换药、救援治疗和死亡；缺失数据记录原因、机制假设、主方法和敏感性方法。

### 安全性分析

记录 TEAE 时间窗、MedDRA 版本、SOC/PT 汇总和分母。检查时间窗起止与分析人群一致性。

### TFL 规格生成

`TFLSpec` 包含表号、标题、行列、统计量、单位、分母和脚注。表壳引用正文中的终点、方法和分析人群。

## Benchmark

专项 Rubrics 包含估计目标、主分析方法、敏感性分析、伴发事件、失访与缺失、安全性分析和 TFL 表壳。本实现提供确定性评分和可选的 Harness LLM-as-a-Judge。
